# Student Enrollment Form

## Description

The Student Enrollment Form is a web-based micro project developed using HTML, CSS, JavaScript, jQuery, and JsonPowerDB.

It allows users to manage student enrollment records through a simple and interactive form. Users can add new student records, retrieve existing records using Roll Number, update student details, and reset the form.

## Benefits of Using JsonPowerDB

- Simple and easy-to-use database.
- Supports JSON-based data storage.
- Provides REST API support.
- Fast data retrieval and record management.
- Reduces the complexity of database operations.
- Useful for developing lightweight web applications.
